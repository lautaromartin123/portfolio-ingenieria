# Pelota con rebote

Animación de una pelota que pierde energía al rebotar.

**[Abrir el código completo](simulacion_rebote.py)** · [Ver las siete simulaciones](../README.md)

## Qué muestra

Detección del contacto con el suelo, inversión de velocidad y coeficiente de rebote.

## Ejecutar en Windows

Abrir esta carpeta en el equipo y hacer doble clic en **INICIAR.cmd**. El lanzador usa el entorno compartido de experimentos, instala las dependencias si faltan y abre esta simulación. Requiere Python disponible en una terminal nueva. La primera ejecución necesita conexión para instalar NumPy y Matplotlib.

También se puede elegir desde [VER_SIMULACIONES.cmd](../VER_SIMULACIONES.cmd), en la carpeta experimentos.

## Procedencia y alcance

Fuente de una práctica presente en WSL. El cálculo y el contenido del script se conservan; la organización y los lanzadores son nuevos. Los ejemplos con TkAgg necesitan un entorno gráfico con Tkinter. Las variantes de superficies forman una progresión del mismo experimento.
