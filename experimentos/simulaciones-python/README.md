# Simulaciones y visualización en Python

Experimentos pequeños con NumPy y Matplotlib: movimiento vertical, rebote, trayectoria en 3D y superficies ilustrativas de potencial.

```sh
python -m pip install -r requirements.txt
python src/simulacion_simple.py
```

Varios ejemplos usan TkAgg y necesitan un entorno gráfico y Tkinter. En WSL puede requerirse WSLg. Son ejercicios de integración numérica/visualización: las superficies denominadas plano Einstein son ilustraciones, no una simulación de relatividad general. Se comprobó sintaxis, no exactitud física de todos los modelos.
