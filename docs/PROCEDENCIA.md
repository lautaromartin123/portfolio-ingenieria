- Consultorios es un trabajo académico grupal. Los comentarios originales que atribuyen tablas y módulos a integrantes se conservan. Esta publicación no reclama autoría exclusiva de todo el sistema.

- El estudio de envejecimiento poblacional de Boa Vista se publica como investigación académica. El Word es una exportación del documento original «TP ENVEJECIMIENTO POBLACION BOA VISTA», sin reescribir su contenido. Los datos y el script de regresión se presentan como material auxiliar.

- Se conservaron los avisos de licencias de dependencias que se distribuyen con fuentes de terceros. Las bibliotecas restaurables no se incluyen.
