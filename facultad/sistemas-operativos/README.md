# Laboratorio Linux y C

Selección de prácticas realizadas en Ubuntu WSL. Los fuentes permiten explorar entrada/salida y los apuntes proponen comandos reproducibles con archivos de demostración.

- [Entrada/salida en C](entrada-salida-c): stdio, llamadas al sistema y redirección.
- [Comandos y texto](comandos-y-texto): búsqueda, filtros y ordenación.
- [Permisos y respaldos](permisos-y-respaldos): permisos y archivo de un directorio de práctica.

No se presenta el árbol planificado como prueba de ejercicios realizados. No se incluyen usuarios del servidor de clase ni volcados de sus sesiones.
