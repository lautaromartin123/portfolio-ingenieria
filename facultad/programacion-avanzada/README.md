Tres soluciones académicas, cada una con su proyecto web y BIZ. Se conservan separadas para mantener referencias y evitar mezclar clases de ejercicios distintos.

| Solución | Conceptos | Estado |
| --- | --- | --- |

Las configuraciones usan una base local genérica. Ninguna solución se conecta a la base original de clase. Los ejemplos pueden provenir de trabajo de clase y no se atribuyen exclusivamente a una persona.
